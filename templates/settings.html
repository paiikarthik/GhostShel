🛡️ Privacy & Security Architecture
100% LOCAL
  • Strict Localhost Loopback: Server binds strictly to 127.0.0.1:5000 to prevent unauthorized local network access.
  • No Cloud APIs: The application does not integrate, fallback to, or transmit data to paid or third-party cloud AI vendors.
  • Zero Disk Persistence for Prompts: Your terminal inputs and questions are kept in temporary volatile browser memory during your session and are discarded upon refresh or closing.
  • Simulated Execution Boundary: All shell commands submitted are scrutinized purely as text strings through static deterministic AST and regular expression parsers. They are never executed via subshells or OS processes.
  • SSRF Protection: The Ollama runtime endpoint is validated to ensure it only communicates with loopback addresses (127.0.0.1 / localhost), preventing internal port scanning or network tampering.
